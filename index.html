Production deployment

This version is designed for a PostgreSQL-backed server and concurrent users. For production, set a strong JWT secret, use HTTPS, restrict CORS to your domain, enable automated PostgreSQL backups, and deploy behind a reverse proxy.

Included

  • PostgreSQL database schema
  • JWT authentication
  • Role-based permissions
  • Password hashing with bcrypt
  • Audit trail
  • Parameterized SQL queries
  • Security headers and compression
  • Excel import/seed tooling

The project package contains deployment instructions for Render, Railway, Fly.io or a VPS.
